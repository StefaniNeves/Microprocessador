

# Projeto de Processador em Arquitetura Monociclo

## Sobre o projeto

Este projeto acadêmico consiste no desenvolvimento de um processador com arquitetura monociclo, realizado como atividade prática da disciplina de Organização e Arquitetura de Computadores, durante a graduação em Ciência da Computação.

O objetivo foi aplicar conceitos relacionados à estrutura e ao funcionamento de processadores, organização de componentes, representação de instruções e programação em Assembly.

O projeto também contempla um programa em Assembly envolvendo operações com matrizes, permitindo trabalhar conceitos de manipulação de dados, estruturas de repetição e operações aritméticas.

## Objetivos do projeto

- Compreender a organização e o funcionamento de um processador monociclo;
- Trabalhar com representação e execução de instruções;
- Desenvolver programas utilizando linguagem Assembly;
- Aplicar conceitos de arquitetura e organização de computadores;
- Integrar conhecimentos teóricos e práticos na implementação do projeto.

## Estrutura do repositório

| Arquivo | Descrição |
|---|---|
| `Processador.circ` | Arquivo do circuito do processador, desenvolvido no Logisim. |
| `matriz.asm` | Programa em Assembly envolvendo operações com matrizes. |
| `código hexadecimal.txt` | Arquivo contendo a representação hexadecimal das instruções. |
| `Relatório do projeto processador em monociclo.pdf` | Documentação técnica com informações sobre o desenvolvimento do projeto. |

## Tecnologias e ferramentas

- **Assembly:** desenvolvimento do programa de operações com matrizes.
- **Logisim 2.7.1:** desenvolvimento e simulação do circuito digital do processador.
- **Representação hexadecimal:** codificação das instruções utilizadas no projeto.

## Como executar o projeto

### 1. Visualizar e simular o circuito do processador

1. Instale o Logisim, compatível com a versão utilizada no projeto (2.7.1).
2. Faça o download ou clone deste repositório.
3. Abra o Logisim.
4. Selecione o arquivo `Processador.circ`.
5. Visualize a estrutura do processador e seus componentes.
6. Utilize os recursos de simulação do programa para observar o funcionamento do circuito.

### 2. Executar o programa em Assembly

1. Instale o simulador MARS ou SPIM, compatível com as instruções utilizadas no código.
2. Abra o simulador.
3. Carregue o arquivo `matriz.asm`.
4. Utilize a opção de montagem (Assemble) para verificar e preparar as instruções.
5. Execute o programa utilizando a opção Run.
6. Acompanhe os resultados apresentados pelo simulador.

**Observação:** a execução do arquivo Assembly em MARS ou SPIM é uma forma de testar o programa separadamente. A integração direta do código com o processador desenvolvido depende da compatibilidade entre o conjunto de instruções e a implementação do circuito.
