
# Projeto de Processador em Arquitetura Monociclo

## Sobre o projeto

Este repositório contém o desenvolvimento de um projeto acadêmico de implementação de um processador com arquitetura monociclo.

O objetivo do trabalho foi aplicar, na prática, conceitos de Organização e Arquitetura de Computadores, explorando a estrutura de um processador, a representação de instruções e a utilização da linguagem Assembly.

## Arquivos do projeto

- **Processador.circ:** arquivo contendo o circuito do processador.
- **matriz.asm:** código desenvolvido em Assembly para a operação envolvendo matriz.
- **código hexadecimal.txt:** arquivo com instruções ou dados representados em hexadecimal.
- **Relatório do projeto processador em monociclo.pdf:** documentação do desenvolvimento e das características do projeto.

## Conceitos trabalhados

- Arquitetura de processadores monociclo;
- Organização e funcionamento de processadores;
- Linguagem Assembly;
- Representação hexadecimal de instruções;
- Estrutura e execução de instruções;
- Organização de componentes de hardware.

## Tecnologias e ferramentas

- Assembly;
- Representação hexadecimal;
- Software de simulação de circuitos digitais compatível com arquivos `.circ`.

## Contexto acadêmico

Projeto desenvolvido durante a graduação em Ciência da Computação, como atividade prática relacionada à disciplina de Organização e Arquitetura de Computadores.

O trabalho proporcionou a aplicação de conhecimentos teóricos na construção e representação de um processador monociclo.
